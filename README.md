# Novelpia Cover Archive

Приложение для Windows 10/11 x64. Следит за обложками, статусами и названиями тайтлов Novelpia и сохраняет PNG в выбранную папку.

**[Скачать установщик 2.1.0](https://github.com/aleksandreev2/novelpiacover/releases/download/v2.1.0/NovelpiaCoverArchive-Setup-2.1.0.exe)** · [Все релизы](https://github.com/aleksandreev2/novelpiacover/releases)

Запустите установочный EXE. Он создаёт ярлыки на рабочем столе и в меню «Пуск» и открывает приложение. Тем же EXE можно обновить установленную версию. Список тайтлов, настройки и файлы архива сохраняются. При необходимости установщик загрузит среду WebView2 от Microsoft.

## Коллекция и журнал

- Добавляйте тайтлы и меняйте настройки коллекции во время проверки. Зелёная рамка показывает текущий тайтл, а счётчик — ход проверки.
- Поиск в «Коллекции» учитывает прежние названия. В карточке тайтла доступна история названий с датами переименований.
- В «Последних событиях» видно, что и когда изменилось. Название ведёт к тайтлу, а превью открывает PNG. Журнал хранит до 500 событий. Датированная история из старого профиля появляется с отметкой «Из истории».
- В настройках есть светлая, тёмная и системная темы. Закрытие окна сворачивает приложение в трей. В меню трея доступны проверка, пауза и выход.
- Проверка идёт каждые 30 минут по умолчанию. Интервал настраивается от 5 до 1440 минут. После сна просроченные проверки возобновляются по таймеру.

## Уведомления и статусы

При нажатии на уведомление Windows открывается нужный тайтл. Настраиваются общие и индивидуальные правила для завершения (`완결`), остановки (`연재중단`), задержки (`연재지연`) и возобновления. При неизвестной разметке сохраняется последний известный статус. Первое наблюдение задаёт исходный статус.

Первая сохранённая обложка видна в журнале. Уведомления об обложках отправляются при последующих новых версиях и настраиваются отдельно. Настройки Windows могут влиять на показ баннера и звук.

## PNG и данные

Для каждого тайтла создаётся папка `Название [ID]`. Имя папки сохраняется при переименовании тайтла. Обычная обложка и оригинал проверяются за один проход. PNG, JPEG, WebP и первый кадр GIF преобразуются в PNG. Если текущий файл удалён, приложение может восстановить его при следующей успешной проверке. При снятии с наблюдения можно оставить архив или отправить папку с обложками в Корзину Windows.

Профиль находится в `%APPDATA%/Novelpia Cover Archive`. Резервная копия настроек сохраняется в `settings.json.bak`. Переменная `NOVELPIA_PROFILE` позволяет использовать отдельный абсолютный путь. Профиль и архив хранятся локально.

## Сборка

Rust и Tauri обслуживают мониторинг, архив, трей и уведомления. Интерфейс HTML, CSS и JavaScript отображается в системном WebView2. Для разработки нужны [средства сборки Rust для Windows](https://v2.tauri.app/start/prerequisites/) и Node.js для сборки NSIS.

```powershell
cargo test --locked --manifest-path src-tauri/Cargo.toml
cargo build --release --locked --manifest-path src-tauri/Cargo.toml
node scripts/smoke-windows.cjs
npm ci --ignore-scripts
curl.exe --fail --location 'https://go.microsoft.com/fwlink/p/?LinkId=2124703' --output assets/WebView2Setup.exe
Get-AuthenticodeSignature assets/WebView2Setup.exe
npm run installer
```

Используйте официальный [загрузчик WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) с действительной подписью Microsoft. Установщик будет в `release/installer`. Проверка `smoke-windows.cjs` запускает отдельный тестовый профиль. Перед ней закройте приложение через трей.
