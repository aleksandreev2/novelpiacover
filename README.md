# Novelpia Cover Archive

Windows-приложение для архива обложек Novelpia и системных уведомлений об изменении статуса тайтлов. Русский интерфейс, несколько новелл, работа в трее.

**[Скачать установщик 1.1.1](https://github.com/aleksandreev2/novelpiacover/releases/download/v1.1.1/NovelpiaCoverArchive-Setup-1.1.1.exe)** · [Все релизы](https://github.com/aleksandreev2/novelpiacover/releases)

## Установка и запуск

Откройте установочный EXE. Он установит приложение для текущего пользователя, создаст ярлыки на рабочем столе и в меню «Пуск», затем запустит программу. Распаковка и Node.js не нужны. Требуются Windows 10/11 x64.

Для обновления запустите установщик новой версии: папка архива, список тайтлов, история обложек и настройки сохраняются. Удаление через настройки Windows оставляет ваши PNG и профиль. Установщик пока без сертификата издателя; Windows может запросить подтверждение запуска.

Нажмите «Добавить новеллу», выберите папку архива и вставьте ссылку. Пример: https://novelpia.com/novel/434103. Закрытие окна сворачивает приложение в трей; полный выход — через меню его значка. Автозапуск Windows включается в настройках.

## Уведомления о статусах

В настройках выберите, о каких переходах оповещать:

| Статус в приложении | Что означает на Novelpia |
| --- | --- |
| Продолжается | Корректный основной блок автора без меток завершения/остановки |
| Завершён | Метка `완결` в основном блоке тайтла |
| Выпуск остановлен | Метка `연재중단` в основном блоке тайтла |
| Выпуск задерживается | Метка `연재지연` в основном блоке тайтла |
| Не определён | Разметка недоступна или не распознана; прежний известный статус сохраняется |

Версия 1.1.1 исправляет ошибку распознавания авторских наград и конкурсных значков и поддерживает настоящий статус задержки выпуска. [Проверка на 59 страницах](docs/status-recognition.md).

Проверены живые страницы [продолжающегося](https://novelpia.com/novel/434103), [завершённого](https://novelpia.com/novel/211530) и [остановленного](https://novelpia.com/novel/330733) тайтлов 2 ноября 2026 года. У продолжающегося тайтла отдельная метка на проверенной странице отсутствовала. Само слово `휴재` («перерыв») в названии, описании или авторском объявлении не считается отдельным подтверждённым статусом сайта. Нерегулярный график, PLUS, эксклюзивность и возрастной рейтинг — отдельные признаки. Из метки остановки не делается вывод о постоянном прекращении работы автора.

По умолчанию включены завершение, остановка, задержка и возобновление, со звуком. Кнопка «Уведомления…» у тайтла позволяет наследовать общие правила или задать собственные события/выключить оповещения. Уведомления о новых обложках включаются отдельно. При нажатии на системное уведомление открывается соответствующий тайтл в приложении.

Первый известный статус, в том числе после обновления с 1.0, принимается за исходный без уведомления об изменении. Последующие переходы сохраняются в истории (последние 200 на тайтл), даже если оповещения выключены. Одинаковые проверки и перезапуски не создают повторов. Ошибка обложки не отменяет подтверждённый переход статуса; ошибка страницы или нераспознанная разметка не создаёт выдуманное «возобновление».

При обновлении с 1.1 задержка добавляется в старые правила «все статусы»; узкие пользовательские фильтры остаются прежними. Неизвестное состояние сопровождается причиной распознавания.

«Проверить уведомление» отправляет настоящее уведомление Windows. Рядом есть переход в системные настройки. Показ баннера и звук также зависят от разрешений Windows и режима «Не беспокоить». Проверки идут, пока программа работает и компьютер включён; после сна выполняется просроченная проверка. По умолчанию интервал — 30 минут, настраивается от 5 до 1440 минут. Статусы читаются в том же запросе, что и обложки, без дополнительных обращений к сайту.

## Архив обложек

В выбранной папке создаётся `Название новеллы [ID]`. Название подпапки закрепляется при первом сохранении. Файлы `время_обнаружения_хеш.png` и журнал `archive.json` содержат исходные ссылки, размеры и время обнаружения (оно не является датой публикации на сайте).

Проверяются обычная обложка и связанный с ней оригинал высокого качества. PNG, JPEG, WebP/`.wimg` преобразуются в настоящий PNG без увеличения разрешения. Анимация сохраняется первым кадром. Одинаковые пиксели и размеры не дублируются; разные разрешения хранятся отдельно. Замена изображения по прежнему URL обнаруживается.

Смена папки влияет на новые сохранения; прежние файлы доступны из истории. Удаление тайтла из наблюдения оставляет файлы и историю для повторного добавления. Удалённый текущий PNG восстанавливается при проверке, если он всё ещё доступен на сайте. Версии, исчезнувшие до начала наблюдения или между проверками, восстановить невозможно.

## Хранение и ограничения

Настройки: `%APPDATA%/Novelpia Cover Archive/settings.json`, резервная копия `.bak`, уменьшенные превью в соседней папке `previews`. Для отдельного профиля задайте переменную `NOVELPIA_PROFILE` абсолютным путём к существующей папке. Архивы PNG лежат только в выбранной папке. Коллекция не отправляется на сторонний сервер, телеметрии нет.

Один сетевой запрос за раз; тайм-аут 30 секунд; HTML до 5 МиБ; изображения до 30 МиБ и 40 млн пикселей, с ограничением до полного декодирования. После ошибок используется задержка с учётом HTTP Retry-After. Проверяются разрешённые URL и каждый редирект. Интерфейс изолирован от Node.js; удалённые скрипты не загружаются. Закрытые страницы не обходятся. Изменение разметки Novelpia может потребовать обновления парсера.

## Разработка

Node.js 24 LTS, Electron 45.2.1, sharp 0.35.5, htmlparser2 12.0.0, чистые JavaScript/CSS без UI-фреймворка. Обработка изображений асинхронная, с ограниченным кэшем и одним потоком libvips. Runtime-библиотеки входят в установщик.

```powershell
npm ci
node node_modules/electron/install.js
npm test
npm start
```

В среде, запрещающей дочерние процессы тестового раннера: `node --test --test-isolation=none tests/*.test.cjs`.

```powershell
npm run smoke
npm run smoke:status
npm run smoke:live
npm run package
npm run installer
```

Интеграционные проверки используют изолированные данные в `.test-data/`, исключённые из дистрибутива и Git. `smoke:status` отправляет тестовые уведомления Windows. `smoke:live` проверяет четыре живых статуса, все четыре тайтла из сообщения об ошибке и отображение их обложек. Для загрузки реальной обложки в обычном smoke-тесте задайте `NOVELPIA_LIVE_TEST=1`.

Сборка: `release/NovelpiaCoverArchive-win32-x64`. Установщик: `release/installer/NovelpiaCoverArchive-Setup-1.1.1.exe`. `NOVELPIA_BUILD_OUT`, `NOVELPIA_PREPACKAGED`, `NOVELPIA_INSTALLER_OUT` позволяют изменить каталоги сборки. CI запускает тесты на каждый push и pull request.

Схема новой функции: [docs/status-notifications.md](docs/status-notifications.md). Изменения версий: [CHANGELOG.md](CHANGELOG.md).

Обложки принадлежат их правообладателям. Приложение не связано с Novelpia.
