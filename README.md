# Novelpia Cover Archive

Windows-приложение на Electron для архивации обычных и полноразмерных обложек Novelpia в PNG. Русский интерфейс, несколько новелл, работа в трее.

## Простая установка — рекомендуется

Откройте `NovelpiaCoverArchive-Setup.exe`. Установщик сам разместит приложение в папке текущего пользователя, создаст ярлыки на рабочем столе и в меню «Пуск», затем запустит приложение. Ничего распаковывать и устанавливать Node.js не нужно.

После запуска нажмите «Добавить новеллу», выберите папку архива и добавьте ссылку. В дальнейшем приложение открывается через ярлык «Novelpia — Архив обложек».

Удаление доступно через «Приложения» в настройках Windows. Удаление приложения сохраняет ваши обложки и настройки. Установщик не подписан сертификатом издателя; Windows может запросить подтверждение запуска.

## Переносная версия ZIP — дополнительный вариант

1. Распакуйте **весь** ZIP в постоянную папку.
2. Запустите `NovelpiaCoverArchive.exe`. Установка Node.js не требуется.
3. Нажмите «Добавить новеллу», выберите папку архива и вставьте ссылку. Ссылка `https://novelpia.com/novel/434103` уже предложена в форме.
4. Текущие обложки сохранятся сразу; дальше программа проверяет обновления каждые 30 минут. Интервал меняется в настройках от 5 до 1440 минут.

Закрытие окна оставляет программу в трее. Полный выход — правой кнопкой по значку в трее → «Выход». Автозапуск Windows включается отдельно в настройках; держите распакованную сборку в постоянной папке.

## Архив

В выбранной папке создаётся `Название новеллы [ID]`. Название подпапки закрепляется при первом сохранении. Файлы: `время_обнаружения_хеш.png`. `archive.json` содержит даты обнаружения, размеры и исходные ссылки; это не время публикации обложки на сайте.

Преобразование в настоящий PNG сохраняет исходные размеры. Проверяются обложка и связанный с ней оригинал. Разные разрешения хранятся отдельно; одинаковые пиксели и размеры не создают дубликат. Замена содержимого по прежнему URL обнаруживается. Повторное появление ранее сохранённой картинки не добавляет ещё один PNG.

При смене папки новые версии сохраняются в новом месте; прежние остаются доступны через историю. Удаление новеллы из наблюдения оставляет файлы и историю для повторного добавления. При удалении текущего PNG проверка восстанавливает его, если изображение всё ещё доступно на сайте.

Настройки хранятся в `%APPDATA%/Novelpia Cover Archive/settings.json` с резервной копией `.bak`. Кэш уменьшенных превью находится рядом в `previews/`. Архивы PNG сохраняются только в выбранную вами папку. Программа не отправляет вашу коллекцию на сервер.

Для собственного расположения профиля можно задать переменную окружения `NOVELPIA_PROFILE` с абсолютным путём к папке до запуска приложения.

## Ограничения

- Нужны Windows 10/11 x64 и доступ к Novelpia. Сборка переносная и не подписана сертификатом издателя.
- Проверки идут, пока программа работает и компьютер не спит. После пробуждения выполняется просроченная проверка.
- Сохраняются версии, доступные во время проверки. Исчезнувшие ранее обложки и изменения между проверками восстановить нельзя.
- Поддерживаются PNG, JPEG, WebP (в том числе `.wimg`) и другие растровые форматы sharp. Анимация сохраняется первым кадром. Закрытые страницы, требования входа и неподдерживаемые форматы отображаются как ошибка. Обход ограничений сайта не выполняется.
- После ошибки повторная попытка назначается с увеличивающейся задержкой; HTTP Retry-After учитывается. Ручная проверка доступна в любой момент.
- Предельный размер: 30 МиБ на изображение, 40 млн пикселей; ограничение проверяется декодером до выделения полного растра.
- Сайт может изменить разметку; извлечение обложек тогда потребуется обновить.

## Разработка

Node.js 22.12+ (проверено на 24.18), Electron 45.2.1, sharp 0.35.5. sharp обеспечивает преобразование WebP/.wimg и асинхронное декодирование изображений без блокировки интерфейса; его бинарные модули включены в готовую сборку.

```powershell
npm install
# Если npm не скачал бинарный runtime:
node node_modules/electron/install.js
npm test
npm start
npm run package
npm run installer
```

Сборка появится в `release/NovelpiaCoverArchive-win32-x64`. Для среды, запрещающей дочерние процессы тестового раннера: `node --test --test-isolation=none tests/*.test.cjs`.

Установщик появится в `release/installer/NovelpiaCoverArchive-Setup.exe`.

Интеграционная проверка: `npm run smoke`. Она использует отдельный профиль в рабочей папке. Для реальной загрузки добавьте переменную окружения `NOVELPIA_LIVE_TEST=1`; это сохранит тестовые обложки в `work/electron-smoke/archive`, не затрагивая обычный профиль.

## Устройство

- `src/novelpia.cjs`: разбор ссылок и разметки; обложка + связанный оригинал.
- `src/http.cjs`: ограниченные запросы, тайм-ауты, проверка каждого редиректа.
- `src/store.cjs`, `src/archive.cjs`: настройки, атомарные записи, журнал и восстановление.
- `src/monitor.cjs`: последовательные проверки, пауза, задержки, история.
- `src/main.cjs`, `src/preload.cjs`: Electron, трей, изолированный API, локальные превью.
- `ui/`: интерфейс без фреймворка, без удалённых скриптов и шрифтов.

Обложки принадлежат их правообладателям. Приложение не связано с Novelpia.
